# @ocelescope/resources

Helpers and React UI components for rendering and exporting Ocelescope
**resources** (the visual artifacts produced by plugins and modules, such as
graphs, tables and plots).

## Installation

```bash
pnpm add @ocelescope/resources
```

## Usage

```tsx
import {
  ResourceViewer,
  Visualization,
  ResourceModal,
  ResourceSelect,
} from "@ocelescope/resources";
```

## About

Part of [Ocelescope](https://github.com/promi4s/ocelescope), a framework for
working with Object-Centric Event Logs (OCEL) developed at the Chair of Process
and Data Science (PADS), RWTH Aachen University.

📖 Documentation: <https://www.ocelescope.org>
